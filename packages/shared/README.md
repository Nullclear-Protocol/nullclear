# @nullclear/shared

Core shared constants, CAIP-2 network configurations, ABIs, and cryptographic schemas for the NullClear protocol.

## Features
- **Networks (`chains.ts`)**: Base Mainnet (8453) & Base Sepolia (84532) contract addresses.
- **ERC-8004 ABIs (`erc8004-abi.ts`)**: Official viem `parseAbi` definitions for Identity and Reputation Registries.
- **x402 V2 Types (`x402-types.ts`)**: Payment options, signatures, EIP-3009 typed data schemas, and Base64 helpers.
- **EIP-712 KYA Schemas (`eip712-kya.ts`)**: Corporate Mandate and Arbiter Clearing Attestation schemas.
